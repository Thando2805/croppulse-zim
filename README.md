# CropPulse Zim 

An AI-powered offline crop disease diagnostic tool engineered to assist farmers and researchers in identifying leaf pathogens, specifically in maize and tomato crops.

##  Key Features
- **Computer Vision Diagnosis:** Upload or capture leaf images to detect plant pathogens instantly.
- **Symptom-Based Diagnostic Engine:** Step-by-step diagnostic workflow for rule-based symptom identification.
- **Treatment & Prevention:** Detailed disease management, chemical control, and preventative guidance.
- **Local History Logging:** Track previous diagnostic scans and history locally without internet connectivity.

## Tech Stack
- **Core Engine:** Python 3.x
- **Machine Learning / Vision:** TensorFlow / Keras, OpenCV
- **Interface & Utilities:** Custom GUI/Web module, SQLite tracking
